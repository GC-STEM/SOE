# STEM Standard Operating Environment

---

> [!WARNING]
> This repository is under active development and may change frequently. It is not ready for student or faculty use

---

## Overview

The STEM Standard Operating Environment (SOE) provides a consistent and controlled setup for Windows, macOS, and Linux systems used across STEM programs and courses. The SOE ensures that all necessary tools and configurations are standardized across different platforms. [Learn more](https://github.com/GC-STEM/SOE).

The SOE is divided into platform-specific repositories for easier management and updates. Click on the link for your platform to get started.

- [**Windows**](https://github.com/GC-STEM/SOE-Windows)
- [**macOS**](https://github.com/GC-STEM/SOE-macOS)
- [**Linux**](https://github.com/GC-STEM/SOE-Linux)
